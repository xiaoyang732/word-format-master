# 论文排版大师

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE.txt)

**用日常中文告诉 AI 你要写什么、怎么排版，帮你生成或整理 Word 论文与报告。**

它主要帮你做两件事：**从零起草论文或报告**，以及**修改已有文档的格式**。你可以提供学校的格式要求、老师给的模板，也可以直接使用内置模板，无需自己写代码或记命令。

## 一、能帮你做什么？

### 1. 从零写一份论文或报告

告诉 AI 主题、用途和已有素材，它会帮你起草内容，并按选定的格式生成新的 Word 文档。

- **有学校或老师的模板**：按照你提供的封面、章节安排和段落格式来写。
- **有文字版格式要求**：按照要求设置字体、字号、行距、页边距、标题和参考文献等。
- **没有现成模板**：课程作业、课题报告默认使用内置的通用课程报告模板；毕业论文可以选择内置的标准学位论文模板。

你的模板和明确要求始终优先。学校、姓名、学号等信息不清楚时保留待填，不会随意编造。实验素材不足时会说明需要补充的内容；示例数据会注明为模拟数据。

> 帮我写一份关于“数据库索引优化”的课程作业报告，用内置模板，保存到 `D:/数据库课程报告.docx`。

> 按照 `D:/学校模板.docx`，结合 `D:/实验记录.txt`，帮我起草一篇论文初稿并排好版。

> 我还没有学校模板，先用内置的标准学位论文模板，根据我的研究大纲生成一份毕业论文初稿。

### 2. 修改已经写好的论文格式

把 Word 初稿交给 AI，再说明格式依据或想修改的地方。

- **按格式要求调整**：对照学校或期刊的要求，统一页面、字体、段落、标题和图表格式。
- **照着样例调整**：参考排好版的论文或空白模板，调整你的文档版式。
- **只修改指定部分**：例如正文行距、一级标题、表格样式或页码。
- **只检查、不修改**：列出格式问题，供你在提交前核对。

修改已有文档时，保留原有正文、数据、公式和图表，并另存为新文件。

> 帮我按照 `D:/学校格式要求.docx`，调整 `D:/我的论文.docx`，另存为 `D:/我的论文-已排版.docx`。

> 只把正文改成宋体小四、1.5倍行距、首行缩进两字符，其他内容保留。

> 对照老师的模板检查我的报告，只列出格式问题，不修改文件。

## 二、怎么开始使用？

### 第一步：让 AI 加载这个技能

将本项目下载到电脑，在支持技能的 AI 工具中加载，或让 AI 阅读项目中的 [技能说明](SKILL.md)。

如果不熟悉安装，可以直接把仓库地址发给 AI，并告诉它：

> 请帮我安装并配置论文排版大师，然后检查能否正常使用。

支持 Windows、macOS 和 Linux，需要 Python 3.10 或更高版本。基础排版不要求安装 Office；如果需要逐页查看实际排版效果，还需要 Word、WPS 或 LibreOffice。依赖清单见 [安装依赖](requirements.txt)。

### 第二步：说明任务并提供材料

写新文档时，尽量说明**主题、用途、大致篇幅和已有素材**；修改旧文档时，提供**原稿路径和格式要求**即可。信息已经在对话中说明过，就不必重复。

| 你想做什么 | 可以怎么说 |
| --- | --- |
| 写课程作业报告 | “帮我写一份计算机网络课程报告，用内置模板。” |
| 按老师的模板写报告 | “按照这份模板，结合我的实验记录写一份报告。” |
| 起草毕业论文 | “根据我的研究素材和学校要求，帮我起草并排版论文。” |
| 整理论文格式 | “按学校规范调整这份论文，另存为新文件。” |
| 局部修改 | “只改正文行距和首行缩进。” |
| 提交前检查 | “只检查格式，给我一份问题清单。” |

### 第三步：查看生成的文档和检查结果

AI 会提供新的 Word 文件，并说明格式检查结果、待填信息和需要你核实的内容。打开后如有目录或页码刷新提示，选择更新，再检查最终分页。

## 三、内置模板和排版能力

| 内容 | 支持情况 |
| --- | --- |
| 通用课程报告模板 | 自带封面填写栏、目录、五章正文、参考文献和附录；章节编号显示为“第一章、第二章……” |
| 标准学位论文模板 | 可用于毕业论文初稿，也可用于统一已有论文格式；提交前仍应对照学校要求 |
| 页面 | 纸张大小、方向、页边距、装订线、页眉页脚位置 |
| 字体和段落 | 中西文字体、字号、加粗、行距、缩进、段前段后间距和对齐方式 |
| 标题和目录 | 多级标题、自动编号、自动目录和页码 |
| 图表和参考文献 | 图表标题、表格样式、跨页表头、参考文献编号和文内引用 |
| 检查 | 核对格式是否生效，检查编号，并在具备办公软件时逐页查看排版效果 |

生成的标题、目录和编号支持在 Word 或 WPS 中更新。增删章节或图表后，可按 `Ctrl+A` 全选，再按 `F9` 更新；部分笔记本需要同时按 `Fn`。

## 四、使用时需要知道什么？

- **保护原稿**：修改结果另存为新文件，保留原稿和参考模板。
- **以你的要求为准**：你提供的学校模板和明确格式要求优先；有实质冲突时会说明并请你选择。
- **区分排版与内容核实**：格式检查通过，不代表实验结论或参考文献已经证实。论文初稿仍需要你检查研究内容和引用来源。
- **排版本身在本地完成**：本地排版程序不会自行上传论文；AI 客户端如何处理你发送的材料，取决于你使用的客户端及其设置。

## 五、常见问题

**没有模板能用吗？**

可以。新写课程或课题报告时会默认使用通用课程报告模板；毕业论文可选择标准学位论文模板。

**学校有自己的格式要求怎么办？**

直接提供要求文件或模板，以学校要求为准。

**支持哪些文件？**

待修改的原稿使用 `.docx`。格式要求可提供 Word、文字版 PDF 或文本文件。旧版 Word 模板需要本机具备相应的办公软件才能转换读取；扫描件通常需要先识别文字。

**没装 Word 能用吗？**

基础排版可以使用。查看实际分页和页面效果时，需要可用的 WPS 或 LibreOffice 等办公软件。

**只想查问题，不想修改文件呢？**

说明“只检查、不修改”，即可得到格式问题清单。
