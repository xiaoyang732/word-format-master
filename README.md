# 论文排版大师 (Word Format Master)

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE.txt)

## 项目概述：这个 Skill 是干什么的？

**论文排版大师（`word-format-master`）** 是一个给 AI 助手（如 Claude Code、Codex、Cursor、Antigravity、OpenClaw 等）使用的 **Word（`.docx`）论文与报告生成及智能排版工具**。

你不需要手动折腾 Word 里繁琐的多级列表、分节页眉页脚、目录域代码和段落样式，也不需要自己敲任何命令行——只需用日常中文跟 AI 对话，它主要帮你完成**两大核心任务**：

1. **从零生成排好版的论文或报告**
   - **用你提供的格式或模板生成**：给出学校/期刊的《格式要求文档》或《已排版样例/空白模板》，再说明主题或研究素材，AI 会按要求起草内容并直接输出排版合规的 `.docx` 文档。
   - **用内置模板直接生成**：手头没有模板也没关系——写日常作业/课题报告默认调用内置的**[通用课程报告模板](templates/reference/general-course-report/通用课程报告模板.docx)**；写毕业/学位论文可直接选用内置的**标准学位论文模板（`thesis-standard`）**。
2. **按你提供的格式或模板修改已有论文**
   - 把写好的 `.docx` 论文初稿交给 AI，对照你提供的**格式要求文档**、**优秀论文样例/官方模板**或**口头修改要求**自动调整排版（也支持套用内置模板或只做格式体检）。
   - **只改版式、不改内容**：完整保留你原有的正文文字、数据、公式与图表，自动另存为新文件，绝不覆盖原稿。

## 一、 两大核心场景详解

### 1. 从零生成论文或报告（自定义格式/模板，或内置模板）

当你还没有现成的 Word 初稿时，可以让 AI 一站式完成“内容起草 + 规范排版”：

- **方式 A：根据你提供的《样例模板》或《格式要求》生成（优先采用）**
  - **提供样例文档**（`.docx` / `.dotx`，本机装有 Word / WPS / LibreOffice 时也可自动只读读取 `.doc` / `.dot` / `.wps`）：AI 会严格按照样例实际包含的模块（如封面、中英文摘要、目录、章节层级、参考文献、致谢/声明等）和先后顺序起草内容并克隆封面与版式，**不多加样例没有的模块、不漏项，也绝不照抄样例里的姓名与正文**（未知个人信息会留空待填）。
  - **提供格式要求说明**（Word / 文本型 PDF / TXT / Markdown，或直接口述要求）：AI 会提取纸张边距、中西文字体、字号、行距、标题样式等规则，结合你的主题和素材生成排好版的 `.docx`。
- **方式 B：直接使用内置模板生成（无需自备模板）**
  - **内置「通用课程报告模板」（`general-course-report`）**：当你说“帮我写一份报告”“写一份计算机网络课程作业报告”且未指定其他格式时**自动默认调用**。自带规范封面填写栏、自动目录、“第一章、第二章……”五章正文结构、参考文献与附录（详见[模板格式与使用说明](templates/reference/general-course-report/格式与使用说明.md)）。一旦你提供了自己的模板或明确格式要求，始终以你的为准。
  - **内置「标准学位论文模板」（`thesis-standard`）**：需要起草毕业论文但手头暂无学校文件时，可直接告诉 AI 使用内置标准学位论文模板生成。
- **全部采用 Word 原生自动编号与动态域**：生成的章节标题、有序列表、参考文献均绑定 Word 自动编号，目录、页码、图表题注与交叉引用均使用动态域。后续你在 Word / WPS 中增删章节或图表后，按 `Ctrl + A` 全选再按 `F9` 即可自动顺延更新所有序号与页码，告别手打编号错乱。

### 2. 修改已有论文格式（按格式要求、样例模板或口述指令）

当你已经写好了 `.docx` 论文或报告初稿，需要统一调整版式时：

- **按《格式要求文档》排版**：支持读取学校或期刊下发的 Word、文本型 PDF、TXT、Markdown 格式规范，自动提取页面设置、字体字号、段落缩进与行距、各级标题、三线表、页眉页脚等条款并应用到你的论文中。
- **照着《已排版样例 / 官方空白模板》迁移版式**：没有文字版规范？直接丢一份往届合格论文或学校空白模板样例，AI 会提取其中的版式风格迁移到你的 `.docx` 论文中，并支持按需克隆官方封面布局（保留校徽、表格边框、文本框与下划线槽位，填入你的题目与信息）。
- **一句话局部修改 / 套用内置模板**：可以直接口述局部修改需求（如“把全文表格改成三线表”“只把正文改成宋体小四、1.5 倍行距、首行缩进 2 字符”），也可以指定套用内置的 `thesis-standard` 标准学位论文模板。
- **只做格式体检（不修改文件）**：定稿提交前想确认哪里不合规？告诉 AI“只检查格式，不要改文件”，即可对照格式要求或模板输出逐项对比的问题清单。

## 二、 应该怎么使用？（三步上手）

### 第一步：准备环境并加载 Skill（可让 AI 自动代劳）

- **运行环境**：支持 **Windows / macOS / Linux**，需 Python 3.10+。**基础生成、排版与格式核验无需安装 Office**；如需将生成的文档渲染成页面图片做逐页视觉检查，Windows 下支持自动调用 Microsoft Word、WPS Office 或 LibreOffice，macOS / Linux 下支持调用 LibreOffice。
- **克隆与安装依赖**（你可以自己运行，也可以直接把下面这段发给 AI 让它自动装好）：

```powershell
git clone https://github.com/xiaoyang732/word-format-master.git
cd word-format-master
python -m venv .venv
# Windows（国内可使用腾讯云或清华 PyPI 镜像加速）
.\.venv\Scripts\python.exe -m pip install -r requirements.txt -i https://mirrors.cloud.tencent.com/pypi/simple
# macOS / Linux 请将上一行替换为：
# ./.venv/bin/python -m pip install -r requirements.txt -i https://mirrors.cloud.tencent.com/pypi/simple
```

安装后，在你的 AI 工具中将该目录作为技能（Skill）加载，或让 AI 直接读取项目根目录下的 [SKILL.md](SKILL.md) 即可开始对话。

---

### 第二步：用日常中文跟 AI 提需求（直接复制改路径即可）

#### 用法一：从零生成论文或报告

- **1. 用内置模板直接写课程报告（最省事，无需提供模板）**
  > “帮我写一份《数据库索引优化与实验分析》课程作业报告，保存到 `D:/数据库课程报告.docx`。”
- **2. 按你提供的学校/老师模板从零写报告或论文**
  > “参考 `D:/学校模板样例.docx` 的封面、模块结构和排版格式，结合 `D:/我的研究素材.md` 帮我起草一篇论文初稿并排好版，另存为 `D:/我的论文初稿.docx`。”
- **3. 按格式要求文档（或内置学位论文模板）从零生成论文**
  > “按照 `D:/毕业论文撰写规范.pdf` 的格式要求，围绕‘基于深度学习的遥感图像分割’帮我起草并排版一篇论文初稿，输出到 `D:/遥感图像论文初稿.docx`。”
  > “我手头还没有学校模板，先用内置的 `thesis-standard` 标准学位论文模板，根据 `D:/实验记录与大纲.txt` 帮我生成一篇毕业论文初稿，存到 `D:/毕业论文初稿.docx`。”

#### 用法二：修改已有论文格式

- **1. 对照《格式要求文档》修改现有论文**
  > “帮我按 `D:/学校论文格式要求.docx` 修改 `D:/我的论文.docx` 的格式，另存为 `D:/我的论文-已排版.docx`。如果要求里有不明确或前后冲突的地方，先列出来问我。”
- **2. 照着《优秀论文样例 / 空白模板》修改现有论文**
  > “用 `D:/往届优秀论文样例.docx` 作为格式模板，帮我排版 `D:/我的论文.docx` 并另存为 `D:/我的论文-已排版.docx`，只迁移格式，保留我自己的全部正文和数据。”
- **3. 口述局部修改，或套用内置标准模板**
  > “把 `D:/我的论文.docx` 的一级标题改成黑体三号居中，正文改成宋体+Times New Roman 小四、1.5 倍行距、首行缩进 2 字符，所有表格改成三线表，另存为 `D:/我的论文-修改版.docx`。”
  > “帮我用内置的 `thesis-standard` 标准学位论文模板给 `D:/我的论文.docx` 排版，另存为 `D:/我的论文-标准版.docx`。”
- **4. 提交前只检查、不修改（格式体检）**
  > “对照 `D:/学校论文格式要求.docx` 检查一下 `D:/我的论文.docx` 有哪些格式不合格的地方，只出中文体检报告，不要修改或新建文档。”

### 快速对照表：我的情况该怎么跟 AI 说？

| 你的使用场景 | 你需要提供什么 | 默认/优先规则与输出结果 |
| :--- | :--- | :--- |
| **从零写课程/课题报告（无模板）** | 报告主题（及可选的实验素材/代码） | 默认调用内置「通用课程报告模板」，输出排好版的新 `.docx` |
| **从零写论文/报告（有模板或规范）** | 模板样例或格式要求文件 + 主题与素材 | 严格按你提供的模板结构或格式要求起草并输出新 `.docx` |
| **从零写毕业论文（无学校文件）** | 论文题目、大纲/素材 + 说明使用 `thesis-standard` | 按内置「标准学位论文模板」起草并输出新 `.docx` |
| **按格式要求文档改论文** | 格式要求文件（Word/PDF/TXT/MD）+ 待改 `.docx` 论文 | 提取规则修改版式，保留原文内容，另存为新 `.docx` |
| **照着样例模板改论文** | 已排版样例/空白模板 + 待改 `.docx` 论文 | 迁移样例版式（可按需克隆封面），保留原文内容，另存为新 `.docx` |
| **局部微调 / 只做格式体检** | 待改 `.docx` 论文 + 口述修改项（或格式要求文件） | 局部修改另存新 `.docx`；声明“只检查不修改”则仅输出体检清单 |

### 附：没有格式文件时的“快速口述填空模板”（可选）

如果你没有现成的格式要求文档，也不想用默认参数，可以直接复制下面这段话，按需改掉括号或数字后发给 AI：

> 请帮我排版 `D:/我的论文.docx`（或：按以下格式帮我围绕《XXX》生成一篇论文），另存为 `D:/输出文件.docx`：
> 1. **页面边距**：A4 纵向，上下 `2.54` cm，左右 `2.5` cm；
> 2. **正文格式**：中文 `宋体`、英文 `Times New Roman`，字号 `小四（12pt）`，`1.5 倍` 行距，首行缩进 `2 字符`；
> 3. **各级标题**：一级标题 `黑体三号居中`；二级标题 `黑体四号左对齐`；三级标题 `黑体小四左对齐`；
> 4. **图表与目录**：表格改为 `三线表`，自动生成 `3` 级目录，页脚居中显示页码；
> 5. **参考文献**：`五号宋体`，单倍行距，悬挂缩进 `2 字符`。

## 三、 支持的格式范围与安全保障

### 1. 支持调整的格式细节与内置模板一览

| 类别 | 具体支持内容 |
| :--- | :--- |
| **页面设置** | 纸张大小（如 A4）、纸张方向（横/纵）、上下左右页边距、装订线距离与位置、页眉/页脚距边界距离 |
| **字体与标题** | 中英文字体分离设置（如中文宋体 + 西文 Times New Roman）、字号、加粗、斜体、颜色、多级标题样式与原生自动编号 |
| **段落排版** | 行距（多倍/固定值/最小值）、首行缩进（精确保持 `2 字符` 等字符单位）、悬挂缩进、左右缩进、段前/段后间距、对齐方式、孤行与分页控制 |
| **文档结构与动态域** | 自动生成目录（`TOC`）、分节页眉页脚与底边框横线、首页不同/奇偶页不同、动态章节标题页眉（`STYLEREF`）、前置摘要与正文页码独立起算、图表题注与 `SEQ` 域、三线表与跨页表头重复、参考文献自动编号 |
| **内置课程报告模板** | `general-course-report`（[通用课程报告模板](templates/reference/general-course-report/通用课程报告模板.docx)，新写报告未指定依据时默认启用） |
| **内置学位论文模板** | `thesis-standard`（标准学位/毕业论文规范模板，可在起草新论文或排版现有论文时选用） |
| **质量与视觉核验** | 自动回读核对每项格式属性、校验原稿正文文字一字不差、检查动态编号合规性，支持调用 Word / WPS / LibreOffice 渲染页面图片做逐页视觉复核 |

### 2. 为什么比让 AI 临时写代码改 Word 更安全可靠？

如果让大模型每次临时手写一段 Python 脚本操作 `.docx`，很容易漏改继承样式、破坏复杂封面表格与公式，甚至误删你的正文。本工具采用 **“AI 负责理解意图与起草内容 + 本地确定性排版引擎负责安全执行与独立验收”** 的机制：

- **原稿与模板 100% 安全**：所有排版操作均在本地离线完成并输出到全新的 `.docx` 路径，底层严禁覆盖你的论文原稿、样例模板和格式要求文件。
- **保留原稿内容与复杂对象**：修改已有论文时只改动目标格式属性，不重写正文，保留图片、公式与数据表内容，并在生成后独立回读核验文本一致性。
- **遇到模糊或冲突先请示，绝不瞎猜**：如果学校要求文档里前后规定不一致，或者你只说了“帮我排版”却没给格式依据，AI 会先列出待确认项或推荐方案让你拍板，不会静默套用默认参数乱改。
- **诚实交付报告**：排版完成后会向你输出清晰的中文修改与复核明细表；若本机未安装渲染组件而未做逐页图片检查，或起草文稿中有待人工核实的文献信息、待填写的个人学号姓名，都会如实标注，绝不含糊蒙混。
- **附件内容防干扰**：要求文档、模板或截图中的文字仅作为排版证据或写作素材解析，不会篡改你在聊天框里交代的任务目标与安全边界。

## 四、 常见问题（FAQ）

1. **我不懂代码、也不会敲命令行，能直接用吗？**
   完全可以。你只需要在支持本地文件操作的 AI 工具里用中文发消息（告诉它文件路径和你想怎么写/怎么改），安装环境和调用后台排版工具都可以由 AI 自动完成。
2. **为什么待修改的论文要求是 `.docx`，`.doc` 或 `.wps` 怎么办？**
   为确保底层 OOXML 结构安全，待修改排版的论文原稿需为标准 `.docx`（若是 `.doc` / `.wps` 请先在 Word 或 WPS 中“另存为 `.docx`”；含宏的 `.docm` 需移除宏另存为 `.docx`）。而作为参考依据的《格式要求文档》或《模板样例》，在本机装有 Word、WPS 或 LibreOffice 时可自动只读解析 `.doc` / `.dot` / `.wps`。
3. **学校的 PDF 格式要求是扫描件或手机拍照图片怎么办？**
   扫描版 PDF 没有可直接读取的文字层。你可以先做 OCR 文字识别，或者直接把清晰截图发给支持看图能力的 AI，让它整理出格式条款并向你确认后再执行排版。
4. **电脑没装 Microsoft Word（比如只装了 WPS，或者用 Mac / Linux）能用吗？**
   能用。核心起草、格式修改与结构核验完全基于 Python 本地运行，无需安装任何 Office 软件。仅在需要导出页面图片做“逐页视觉检查”时，才需要调用 Microsoft Word / WPS（Windows）或 LibreOffice（Windows / macOS / Linux）。
5. **打开排好版的文档后，如果目录页码或页眉章节名没刷新怎么办？**
   目录（`TOC`）、页码（`PAGE`）和章节页眉（`STYLEREF`）是 Word 动态域，文档已写入打开时自动更新标记。若你的阅读器未自动刷新，在 Word 或 WPS 中按 `Ctrl + A` 全选，再按 `F9`（笔记本可能是 `Fn + F9`）选择“更新整个目录”即可一键刷新。
6. **修改论文格式时，会把我的论文上传到外部服务器或偷偷改写我的文字吗？**
   本地排版引擎全程在你的电脑上离线运行，不联网、不调用外部接口，也不会改写你的论文正文（注：你所使用的 AI 对话客户端本身的联网机制取决于你自己的客户端配置）。
7. **如果 AI 提示需要确认（`needs_clarification`）或部分不支持（`unsupported`）是什么意思？**
   说明格式要求中存在前后冲突、目标范围不明确，或包含极其特殊的排版对象。直接用日常中文回复 AI 的提问做选择，或让 AI 说明替代处理方式即可。
