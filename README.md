# 论文排版大师 (Word Format Master)

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE.txt)

通过日常中文对话生成 Word（`.docx`）论文与报告，或修改已有文档格式。无需记命令，也不必手动逐段调整样式表、多级编号和分节页码，主要解决两类需求：

- **使用你的模板或内置模板，从零生成论文**：根据你提供的学校模板、格式要求，或直接使用内置模板，起草内容并生成排好版的论文（同样支持日常课程与课题报告）。
- **根据你的需求，修改已有论文格式**：对照学校的格式规范、参考样例或你的具体修改要求，调整现有论文初稿的版式；也可以只检查格式问题、不改动原文件。

## 能帮你做什么

### 1. 使用你的模板或内置模板，从零生成论文

还没有现成初稿时，告诉 AI 论文主题、提纲或实验记录，即可直接生成排好版的 Word 文档：

- **按学校模板或样例生成**：提供学校下发的空白模板或排好版的论文样例，按其中的封面（保留校徽与填写栏）、中英文摘要、目录、章节结构和字体行距成文，不随意增删模块，也不会照抄样例中的个人信息。
- **按文字版格式要求生成**：提供学院的格式规范（支持 Word、文字版 PDF 或文本说明），自动设置页边距、中西文字体、字号、行距、标题样式与参考文献格式。
- **使用内置模板生成**：
  - **毕业论文 / 学位论文**：手头暂时没有学校模板时，可选用**内置标准学位论文模板**生成初稿（正式提交前仍建议对照本校要求核对）。
  - **课程作业 / 课题报告**：未指定其他模板时，自动采用**内置通用课程报告模板**，自带封面填写栏、自动目录、五章正文结构、参考文献与附录。

你提供的模板和要求始终优先。学校、姓名、学号等信息不清楚时会留空待填；研究素材不足时会提示补充，演示用的示例数据会注明为模拟数据。

### 2. 根据你的需求，修改已有论文格式

写好论文初稿后，把 `.docx` 文件和修改要求发给 AI 即可整理排版：

- **按规范整篇统一**：根据学校或期刊的格式规定，统一页面边距、字体字号、行距缩进、多级标题、自动目录、页眉页脚、页码、三线表与参考文献格式。
- **照着参考样例调整**：参考一份已排好版的论文或空白模板，把你的初稿调整成相同版式。
- **按要求局部调整**：只想改某几项时直接说明，比如只调整正文行距、一级标题字号，或把表格改成三线表，未提及的部分保持不变。
- **只检查不修改**：交稿前对照规范检查一遍，直接输出中文格式问题清单，原文件不做任何改动。

修改已有文档时完整保留原有的正文、数据、公式和图片，并另存为新文件，不会覆盖原稿。

## 怎么开始使用

### 1. 加载技能

在支持技能（Skill）的 AI 工具（如 Claude Code、Cursor、Codex、Antigravity、OpenClaw 等）中加载本项目，或直接把项目地址发给 AI：

> “请帮我安装并配置论文排版大师，检查能否正常使用。”

安装后可让 AI 先运行 `python scripts/format_cli.py doctor`。它会分别检查核心依赖、默认模板、任务目录和页面渲染条件；缺少办公软件时仍可进行核心排版，页面检查会注明未完成。可追加 `--output-dir "现有任务目录"` 检查写入权限，或 `--probe-render` 在临时目录实际探测渲染。

### 2. 提交材料并说明需求

从零写论文时说明**主题、提纲或素材、使用的模板**；改已有论文时提供**原稿路径和修改要求**即可。

| 你的需求 | 直接这样说 |
| :--- | :--- |
| **按学校模板从零写论文** | “按照 `D:/学校模板.docx` 和我的研究提纲，结合 `D:/实验记录.txt` 写一篇毕业论文初稿并排好版。” |
| **用内置模板从零写论文** | “我还没有学校模板，先用内置标准学位论文模板，根据我的实验笔记起草一篇论文初稿。” |
| **用内置模板写课程报告** | “帮我写一份关于数据库索引优化的课程报告，直接用内置模板，保存到 `D:/课程报告.docx`。” |
| **整篇统一已有论文格式** | “对照 `D:/学院格式规范.pdf` 修改 `D:/我的论文初稿.docx` 的排版，另存为 `D:/我的论文-已排版.docx`。” |
| **局部修改几项格式** | “只把这篇论文的正文改成宋体小四、1.5 倍行距、首行缩进两字符，表格改成三线表，其他不动。” |
| **提交前只检查问题** | “对照老师的模板检查 `D:/我的论文初稿.docx` 有哪些格式不合规的地方，只列清单，不要改原文件。” |

### 3. 查看生成的文档与检查报告

完成后，AI 会交付新的 `.docx` 文件，并附上一份中文格式修改（或检查）汇总表及待填信息提示。在 Word 或 WPS 中打开文档（或后续增删了章节、图表）后，按 `Ctrl + A` 全选再按 `F9`（部分笔记本为 `Fn + F9`）即可刷新目录和页码。

## 完整成果示例

以下是一次典型的“修改已有论文格式”交付结果（从零生成论文同样会输出完整的 `.docx` 文档与这份核对报告）：

**你的输入：**

> “对照 `D:/学院格式规范.pdf`，帮我修改 `D:/毕业论文初稿.docx`，另存为 `D:/毕业论文-已排版.docx`。”

**交付成果 1：排好版的新 Word 文档（`D:/毕业论文-已排版.docx`）**

- **封面与摘要节**：保留原封面填写栏与校徽，中英文摘要与关键词按规范分设样式，前置部分不显示页码。
- **自动目录节**：自动生成可点击跳转的三级目录，打开或修改章节后可一键更新页码。
- **正文章节（第 1 页起算）**：章节标题、图表题注、公式与文内文献引用均绑定 Word 自动编号；正文中文宋体、西文 Times New Roman 小四号，数据表统一为跨页重复表头的标准三线表。
- **参考文献与致谢**：文献条目五号字、悬挂缩进 2 字符并自动顺序编号，原稿数据与图片完整保留。

**交付成果 2：配套的中文格式核对表**

| 模块 | 格式项 | 原稿状态 | 调整后结果 | 状态 |
| :--- | :--- | :--- | :--- | :--- |
| 页面与页码 | 纸张 / 页边距 / 页码 | 左右边距 3.18cm，全文连排页码 | A4，上下 2.54cm、左右 2.50cm；正文第 1 章起第 1 页居中页码 | 已生效 |
| 中英文摘要 | 标题 / 正文 / 关键词 | 标题与正文同为等线 11pt | 摘要标题黑体三号居中，正文宋体小四 1.5 倍行距，“关键词：”加粗 | 已生效 |
| 目录与标题 | 自动目录 / 一至三级标题 | 手打目录与章节序号 | 生成三级自动目录；一至三级标题采用多级自动编号（三号/四号/小四黑体） | 已生效 |
| 正文与图表 | 字体行距 / 三线表 / 题注 | 单倍行距，普通网格表 | 宋体 + Times New Roman 小四，首行缩进 2 字符；表格改为三线表 | 已生效 |
| 参考文献 | 编号与缩进 | 手敲 `[1]` 且无缩进 | 五号宋体/Times New Roman，单倍行距，悬挂缩进 2 字符 | 已生效 |

> **待填与提示**：原稿 `D:/毕业论文初稿.docx` 未修改；封面“学号、指导教师”原稿为空已保留待填；打开新文档后如有提示，确认更新域即可同步最新目录页码。

## 支持调整的排版项

| 类别 | 支持内容 |
| :--- | :--- |
| **封面与结构** | 保留模板中的校徽图片与封面填写栏；排布中英文摘要、关键词、目录、正文章节、参考文献、致谢与附录 |
| **页面与页码** | 纸张大小、方向、页边距、装订线；前置部分无页码、正文从第 1 页重新连续计页；页眉文字与页眉底线 |
| **字体与段落** | 中文字体（如宋体、黑体）与西文字体（如 Times New Roman）分别设置；字号、加粗、行距、首行与悬挂缩进、段前段后间距、对齐方式 |
| **目录与自动编号** | 自动生成多级目录；章节标题、列表、图表题注、页码与文献序号均使用 Word 自动编号，增删内容后刷新即可顺延 |
| **图表与文献** | 图题置下、表题置上；标准三线表与跨页重复表头；参考文献悬挂缩进及正文数字引用关联 |
| **核对与页面检查** | 修改后逐项核对格式是否生效；本机装有办公软件时，可导出页面逐页检查实际分页效果 |

## 常见误区与问题速查

| 常见问题 / 易错情况 | 说明与解决办法 |
| :--- | :--- |
| **不会写代码、不懂命令行能用吗？** | 可以。排版程序由 AI 在后台自动调用，平时只需用中文发消息、给文件路径。 |
| **手里还没有学校模板能先写论文吗？** | 可以。毕业论文可选内置标准学位论文模板，课程作业或课题报告自动使用内置通用课程报告模板；后续拿到学校模板后，还能把初稿按新模板重新排版。 |
| **老版 `.doc` / `.wps` 或扫描版 PDF 能用吗？** | 待直接修改排版的原稿请先在办公软件里另存为 `.docx`。参考用的格式要求支持 Word、文字版 PDF 和文本文件；老版 `.doc`/`.wps` 模板在装有办公软件时可只读读取；扫描件请先识别文字或发清晰截图。 |
| **手动敲“第一章”“图 1-1”可以吗？** | 不建议手敲序号。生成的章节、图表和文献均为自动编号，增删内容后按 `Ctrl + A` 再按 `F9` 即可自动顺延更新，不会出现序号错乱或目录对不上。 |
| **电脑没装 Microsoft Word 能用吗？** | 能用。起草、修改格式与结构检查不依赖 Microsoft Word；仅在导出页面图片做逐页版面检查时，需要本机装有 Word、WPS 或 LibreOffice。 |
| **要求前后矛盾怎么办？原稿会改坏或上传吗？** | 规则冲突或不明确时，AI 会先列出选项请你拍板。排版程序在本地离线运行，只另存新文件、不覆盖原稿，也不会自行上传文档（对话内容本身的传输取决于你使用的 AI 客户端设置）。 |
