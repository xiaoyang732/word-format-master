## 项目概述

**论文排版大师（Word Format Master）** 是一款面向 AI 助手（Claude Code、Cursor、Codex、Antigravity、OpenClaw 等）的 Word（`.docx`）论文与报告生成及确定性排版技能。无需记忆复杂命令，也不必手动逐段调整样式表、多级编号、目录域、三线表与分节页码，通过日常中文对话即可驱动本地 OOXML 排版引擎完成写作与排版，并通过**属性回读 + 原生编号核验 + 逐页视觉审查**闭环交付成品文档：

- **使用你的模板或内置模板，从零生成论文与报告**：根据你提供的学校模板、格式范文、书面格式要求，或直接使用内置模板，起草内容并生成版式规范的论文、文献综述、课程作业与课题报告。
- **根据你的需求，修改或检查已有论文格式**：对照学校或期刊的格式规范、参考样例或具体修改要求，调整现有初稿版式并另存新文件；也可以只做格式体检、输出中文问题清单而不改动原文件。

## 能帮你做什么

### 1. 使用你的模板或内置模板，从零生成论文与报告

还没有现成初稿时，告诉 AI 论文主题、研究提纲或实验记录，即可直接生成排好版的 Word 文档：

- **按学校模板或格式范文生成**：提供学校下发的空白模板或排好版的论文样例（支持 `.docx` / `.dotx`，本机装有办公软件时也支持只读提取 `.doc` / `.wps` 模板），原样克隆封面（保留校徽、艺术字横幅、分栏填写栏与下划线，自动清理模板中的红色格式提示并在长标题换行时单页自适应收口），严格按样例排布中英文摘要、关键词分隔符、目录、章节结构与字体行距，不随意增删模块，也不会照抄样例中的个人信息。
- **按文字版格式要求或双端依据生成**：提供学院的格式规范（支持 Word、文字版 PDF、TXT 或 Markdown），自动设置纸张边距、中西文字体、字号行距、标题样式与参考文献格式。**同时提供文字版考核要求与格式范文时**，会自动提取双端依据并逐项核对冲突（如字号、对齐、页眉横线、分节页码、目录收录范围），列出冲突项请示或按优先级消解，不私自混搭。
- **使用内置模板快速起草**：
  - **毕业论文 / 学位论文**：手头暂时没有学校模板时，可选用**内置标准学位论文模板**（`thesis-standard`）生成初稿（正式提交前仍建议对照本校要求核对）。
  - **课程作业 / 课题报告**：未指定其他模板时，自动采用**内置通用课程报告模板**（`general-course-report`），自带封面填写栏、自动目录、五章正文结构、参考文献与附录。

> **真实性与质量门禁**：你提供的模板和要求始终优先。学校、姓名、学号等信息未知时留空待填；研究素材不足时会提示补充，演示用的示例数据明确标注为模拟数据；内置正文字数、摘要字数、近三年文献数量与 **100% 文献双向引用核验**，文末文献与正文引用一一对应，严禁捏造虚假文献。

### 2. 根据你的需求，修改或检查已有论文格式

写好论文初稿后，把 `.docx` 文件和修改要求发给 AI 即可整理排版：

- **按规范整篇统一**：根据学校、学院或期刊的格式规定，统一页面边距、字体字号、行距缩进、多级标题、自动目录、分节页眉页脚、正文独立起算页码、标准三线表与参考文献格式。
- **照着参考样例调整**：参考一份已排好版的论文范文或空白模板，把你的初稿调整成相同版式（自动清理原稿残留的日文/西文主题字体与默认蓝字标题）。
- **按要求局部微调**：只想改某几项时直接说明，例如只调整正文行距、一级标题字号、关键词分隔符，或把表格改成三线表，未提及的部分保持原样。
- **只检查不修改**：交稿前对照规范或模板全面体检，直接输出中文格式问题清单，原文件不做任何改动。

> **原稿零破坏保护**：修改已有文档时完整保留原有的正文、数据、公式、图片、书签与超链接，所有排版结果经临时文件校验通过后另存为新文件，绝不覆盖原稿或参考模板。

## 怎么开始使用

### 1. 加载技能与环境自检

在支持技能（Skill）的 AI 工具（如 Claude Code、Cursor、Codex、Antigravity、OpenClaw 等）中加载本项目，或直接把项目路径发给 AI：

> “请帮我安装并配置论文排版大师，检查能否正常使用。”

首次使用可让 AI 运行 `python scripts/format_cli.py doctor` 自检运行环境。它会分别检查 Python 核心依赖、内置模板指纹、任务目录权限和办公软件渲染条件；缺少办公软件时仍可完成全部核心排版与结构回读，页面视觉检查会如实注明未执行。可追加 `--output-dir "现有任务目录"` 检查写入权限，或 `--probe-render` 在临时目录实际探测页面导出。

### 2. 提交材料并说明需求

从零写论文时说明**主题、提纲或素材、使用的模板/要求**；改已有论文时提供**原稿路径和修改依据**即可：

| 你的需求 | 直接这样对 AI 说 |
| :--- | :--- |
| **按学校模板从零写论文** | “按照 `D:/学校模板.docx` 和我的研究提纲，结合 `D:/实验记录.txt` 写一篇毕业论文初稿并排好版。” |
| **结合考核要求与范文写论文** | “对照 `D:/考核要求.docx` 和 `D:/格式范文.doc`，按我的提纲起草一篇文献综述并完成排版验收。” |
| **用内置模板从零写论文** | “我还没有学校模板，先用内置标准学位论文模板，根据我的实验笔记起草一篇论文初稿。” |
| **用内置模板写课程报告** | “帮我写一份关于数据库索引优化的课程报告，直接用内置模板，保存到 `D:/课程报告.docx`。” |
| **整篇统一已有论文格式** | “对照 `D:/学院格式规范.pdf` 修改 `D:/我的论文初稿.docx` 的排版，另存为 `D:/我的论文-已排版.docx`。” |
| **局部修改几项格式** | “只把这篇论文的正文改成宋体小四、1.5 倍行距、首行缩进两字符，表格改成三线表，其他不动。” |
| **提交前只检查问题** | “对照老师的模板检查 `D:/我的论文初稿.docx` 有哪些格式不合规的地方，只列清单，不要改原文件。” |

### 3. 查看生成的文档与检查报告

完成后，AI 会交付新的 `.docx` 文件，并附上一份中文格式修改（或检查）汇总表及待填信息提示。在 Word 或 WPS 中打开文档（或后续增删了章节、图表、文献）后，按 `Ctrl + A` 全选再按 `F9`（部分笔记本为 `Fn + F9`）即可一键刷新目录、题注和页码。

## 完整成果示例

以下是一次典型的“修改已有论文格式”交付结果（从零生成论文同样会输出完整的 `.docx` 文档与这份核对报告）：

**你的输入：**

> “对照 `D:/学院格式规范.pdf`，帮我修改 `D:/毕业论文初稿.docx`，另存为 `D:/毕业论文-已排版.docx`。”

**交付成果 1：排好版的新 Word 文档（`D:/毕业论文-已排版.docx`）**

- **封面与摘要节**：保留原封面填写栏与校徽，中英文摘要与关键词按规范分设样式与分隔符，前置部分独立分节控制页码。
- **自动目录节**：自动生成可点击跳转的三级目录（按规范收录正文章节与参考文献），打开或增删章节后可一键同步页码。
- **正文章节（第 1 页起算）**：章节标题、图表题注、公式与文内文献引用均绑定 Word 原生自动编号与动态域；正文中文宋体、西文 Times New Roman 小四号、两端对齐，数据表统一为跨页重复表头且防跨页断行的标准三线表。
- **参考文献与致谢**：文献条目五号字、悬挂缩进 2 字符并自动顺序编号，原稿数据、公式与图片完整保留。

**交付成果 2：配套的中文格式核对表**

| 模块 | 格式项 | 原稿状态 | 调整后结果 | 状态 |
| :--- | :--- | :--- | :--- | :--- |
| 页面与页码 | 纸张 / 页边距 / 页码 | 左右边距 3.18cm，全文连排页码 | A4，上下 2.54cm、左右 2.50cm；正文第 1 章起第 1 页居中页码 | 已生效 |
| 中英文摘要 | 标题 / 正文 / 关键词 | 标题与正文同为等线 11pt | 摘要标题黑体三号居中，正文宋体小四 1.5 倍行距，“关键词：”加粗 | 已生效 |
| 目录与标题 | 自动目录 / 一至三级标题 | 手打目录与章节序号 | 生成三级自动目录；一至三级标题采用多级自动编号（三号/四号/小四黑体） | 已生效 |
| 正文与图表 | 字体行距 / 三线表 / 题注 | 单倍行距，普通网格表 | 宋体 + Times New Roman 小四，首行缩进 2 字符；表格改为三线表并防断行 | 已生效 |
| 参考文献 | 编号与缩进 | 手敲 `[1]` 且无缩进 | 五号宋体/Times New Roman，单倍行距，悬挂缩进 2 字符，自动顺序编号 | 已生效 |

> **待填与提示**：原稿 `D:/毕业论文初稿.docx` 未修改；封面“学号、指导教师”原稿为空已保留待填；打开新文档后如有提示，确认更新域即可同步最新目录页码。

## 支持调整的排版项

| 类别 | 支持内容 |
| :--- | :--- |
| **封面与文档结构** | 原样克隆模板中的校徽图片、艺术字横幅与封面填写表（自动清理模板红色格式提示并单页自适应收口，确保封面与摘要页题目 100% 一致）；严格按样例或规范排布中英文摘要、关键词、目录、正文章节、参考文献、声明/致谢与附录 |
| **页面、分节与页眉** | 纸张大小、方向、页边距、装订线；前置部分与正文（从第 1 页重新连续计页）真实分节独立控制；各节及首页/奇偶页页眉文字、动态章节域（`STYLEREF`）与页眉底线 |
| **字体、段落与关键词** | 中文字体（宋体、黑体、楷体等）与西文字体（Times New Roman 等）双通道独立设置；字号、粗体、颜色、行距、首行与悬挂缩进、段前段后间距、两端对齐与居中；中英文关键词标签加粗及分隔符（`；`、`，`、`、`、`; ` 等）识别与统一 |
| **自动目录与原生编号** | 自动生成多级目录（支持按层级独立控制字体与阶梯缩进、收录“参考文献”等模块并同步引导符字体）；章节标题（`w:numPr`）、列表、图表题注（`SEQ`）、页码（`PAGE`）与文献序号均采用 Word 原生自动编号或动态域，增删内容后刷新即可顺延 |
| **三线表与文献引用** | 图题置下、表题置上并与相邻对象同页绑定；标准三线表、跨页重复表头、行内防跨页拆分（`cantSplit`）与表头同页保护（`keepNext`）；参考文献悬挂缩进、近三年文献核验及正文数字引用（`REF` 动态域，支持上标或同行平齐）100% 双向关联 |
| **多重回读与逐页验收** | 修改后逐项回读核对格式属性、结构契约、原生编号以及正文字数/摘要字数；支持调用本机 Microsoft Word 或独立 WPS 进程刷新动态域、核验 Word 语义并导出页面快照，按六项版面清单逐页审查实际排版效果（详见 [Office 兼容性与验收](references/office-compatibility.md)） |

## 常见误区与问题速查

| 常见问题 / 易错情况 | 说明与解决办法 |
| :--- | :--- |
| **不会写代码、不懂命令行能用吗？** | 可以。排版引擎由 AI 在后台自动调用，平时只需用中文发消息、提供文件路径即可。 |
| **手里还没有学校模板能先写论文吗？** | 可以。毕业论文可选内置标准学位论文模板，课程作业或课题报告自动使用内置通用课程报告模板；后续拿到学校模板后，还能把初稿按新模板重新排版。 |
| **老版 `.doc` / `.wps` 或扫描版 PDF 能用吗？** | 待直接修改排版的原稿请先在办公软件里另存为 `.docx`。参考用的格式要求支持 Word、文字版 PDF 和文本文件；老版 `.doc` / `.wps` 模板在装有 Word 或 WPS 时可自动只读转换提取；扫描件请先识别文字或提供清晰截图。 |
| **手动敲“第一章”“图 1-1”“[1]”可以吗？** | 不建议手敲序号。生成的章节、图表和文献均为 Word 原生自动编号与动态域，增删内容后按 `Ctrl + A` 再按 `F9` 即可自动顺延更新，不会出现序号错乱或目录页码对不上。 |
| **电脑没装 Microsoft Word 能用吗？** | 能用。起草、修改格式、结构回读与编号检查均不依赖 Microsoft Word；在导出页面图片做逐页版面检查或刷新动态域时，支持按本机环境自动或显式选用 Microsoft Word、独立 WPS Office 或 LibreOffice。 |
| **要求前后矛盾怎么办？原稿会改坏或上传吗？** | 规则冲突或不明确时，AI 会先列出证据与选项请你拍板。排版引擎在本地离线运行，只另存新文件、不覆盖原稿，也不会自行上传文档（对话内容本身的传输取决于你使用的 AI 客户端设置）。 |

## 环境与项目说明

支持 Windows、macOS 和 Linux，需 Python 3.10 及以上版本，核心依赖见 [requirements.txt](requirements.txt)。

项目采用**“AI 语义理解 + 本地确定性 OOXML 引擎”**架构：由 AI 解析自然语言需求、格式规范与文稿结构，调用本地命令行流水线（`scripts/format_cli.py` 与 `scripts/run_format_pipeline.py`）完成证据提取、冲突消解、计划构建、原子写入、独立属性回读、原生编号核验与逐页视觉签收。

```text
自然语言 / 规范文档 / 格式范文
  → 格式档案提取 (profile) 与冲突决策 (resolutions / mapping)
  → 结构检查 (check-structure) 与排版规划 (plan)
  → 原子写入 (apply) → 属性回读与原生编号核验 (verify / check_numbering)
  → 动态域刷新与页面渲染 (refresh-fields / render) → 多模态逐页看图签收 (summary.json)
```
