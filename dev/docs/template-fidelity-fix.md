# 模板格式识别与验收修复记录

本次修复针对可复用的模板识别、格式映射、目录生成和验收链路，
具体测试样例的字号不作为通用默认值。

## 问题与修复

- 封面大标题、题目、姓名、学院、专业、导师、学号及日期分别识别，
  摘要题目、标签和正文按语言映射，避免粗粒度模块混合格式。
- 关键词标签与词条分别提取字体证据并执行字符范围操作；
  空词条和空摘要占位不推定正文格式。
- 规范按显式目标分句，段落间不沿用上段目标；
  独立材料的规范保留适用范围问题，不自动覆盖主论文。
- “加黑”表示粗体，“黑体”表示字体家族；支持否定粗体及数字字号写法，
  固定行距不再误作字号。中西文字体通道保持独立。
- 目录支持标准及自定义大纲、保守确认的编号标题，只补充缺失大纲级别，
  保留现有字体、样式和编号；显式正文级别不纳入目录。
- 目录验收检查真实条目及顺序，拒绝空缓存、占位提示和目录错误。
  仅替换完整独立的旧目录域，保护混合正文、其他域和分节边界。
- 支持原生行单位段前/段后距；超过可用页宽的模板首行缩进需复核。
- 计划报告列明每个目标实际检查的属性，不能将段落命中视为完整格式覆盖。
  起草文件必须继续经过 plan/apply/verify，不能以 inspect 或渲染替代验收。
