# 历史模板与来源归档

这里保存项目调研过的学校报告模板、原件及转换副本，供溯源与对照。当前运行模板由根目录 `templates/reports.json` 和 `templates/builtin/` 管理。

- [天华学院课程考核报告原版](reference/course-report-tianhua/SOURCE.md)：当前通用课程报告模板的来源原件、DOCX 转换副本、下载记录及格式核对说明。
- [南京城市职业学院课题报告](reference/school-report/SOURCE.md)：此前考察的学校课题报告原版与来源说明。
- [其他学校报告详例](reference/downloaded-school-reports/SOURCE.md)：中国石油大学（北京）课题研究报告、哈尔滨工程大学课程设计报告，以及对应转换副本和来源记录。

原件和转换副本保持归档时的文件内容与校验值。默认报告生成不读取此处模板。
