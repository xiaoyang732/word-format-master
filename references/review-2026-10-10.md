## Findings and decisions

| Priority | Finding | Evidence | Change |
|---|---|---|---|
| P1 | Independent `verify` gave a false pass with missing, empty or truncated report checks. | Reproduced with a two-target plan: all three malformed reports returned `passed`. `verify_plan` previously consumed `report.get("checks", [])` without comparing to plan targets. | Check every operation/target/parameter exactly once, reject retargeting without structural ID shifts and rerun structural acceptance on the output. |
| P1 | A render could combine an earlier PDF/page set with a later source hash if the source changed during conversion; an unsuccessful retry could leave an old manifest in the output directory. | Old `render_document` converted the original path and computed `source_sha256` only after rasterizing. | Render a byte-identical temporary DOCX snapshot, check the source hash before publication, stage page files, invalidate the prior manifest on a new attempt and atomically publish the new manifest after all pages are ready. |
| P2 | A task-local render snapshot changes how relative external relationships resolve. | Word treats relative `TargetMode=External` paths as relative to the DOCX location. | Detect and reject those links before rendering with a clear error; such files need linked assets resolved or embedded first. |
| P2 | A read-only request could inspect or call structural `verify_output`, but had no unified per-target comparison with the same selector and effective-value reader used by formatting. | Existing `inspect` lists values; a `plan` requires a destination; the skill advertised an audit route. | Add `format_cli.py audit`, which resolves operations without writing, reports per-target effective values and uses the structural verifier. Its coverage is only the properties explicitly requested. |
| P2 | Malformed `target` and `action` shapes could raise uncaught `AttributeError`/`TypeError`. | A `target` of `null`, `[]` or `4` crashed planning at `.get`. | Validate those types at the planner boundary and return a normal `FormatError`. |
| P2 | The browser regression check was not reproducible in a fresh checkout or exercised in CI. | Initial `node tests/test_dashboard_ui.cjs` failed with `Cannot find module 'playwright'`. | Pin a Playwright development dependency, let the test start its own loopback Dashboard, and add a dedicated Windows UI CI job. |
| P2 | Metadata described the project-maintained generic parameter set as strict national-standard compliance. | `assets/presets.json` asserted strict GB/T conformance although many numeric choices are project choices and school templates vary. | Make the scope and authority hierarchy explicit without changing the preset values. |

## What the other projects suggest next

1. **Institution rule packs, after a documented source is supplied.** `academic-research-skills` demonstrates a useful rule-file boundary and alternative margin profiles. Build a converter into this project's supported spec tokens, with source/version/evidence for each field; do not import any university profile as a universal default.
2. **A synthetic fidelity corpus.** `paper_format_agent` lists known content-fingerprint gaps. Add synthetic DOCX cases with footnotes, OMML equations, nested/merged tables, section-linked headers, content controls and REF/TOC fields. Compare package parts and authored content across apply and render, and publish explicit unsupported cases.
3. **An optional conversion route.** `software-thesis-docx-skill` and `docx-template-translator-skill` are useful when the source is Markdown, LaTeX or a repository rather than an existing DOCX. Keep conversion separate from this project's formatting core, then hand the resulting DOCX to the same inspect/audit/verify gates.
4. **Cross-renderer fixtures.** `thesis-docx` highlights style overrides, page/section drift and stale REF results. Test representative official templates in the actual target Word/WPS/LibreOffice environment, compare every rendered page and report renderer-specific differences rather than claiming a generic pass.
