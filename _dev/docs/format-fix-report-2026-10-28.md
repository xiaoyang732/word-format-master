# 模板格式识别与验收修复记录

修改项目：`D:\project\word-format-master`。本次修改针对通用识别、执行和验收链路，不将某篇论文的字号写成全局默认值。

## 根因与修改

1. **失败结果绕过了项目排版链路。** 测试目录中的 `build_thesis_document.py` 自行指定了封面、摘要、关键词和正文标题格式，直接保存 DOCX。该结果只有 inspect/渲染记录，缺少绑定到最终文件的 plan、apply、verify 证据。因此，不能说是核心验收接受了该失败文件。
2. **模板区域划分过粗。** 原提取器把封面元数据归成通用 module_body，摘要题目也可能归入前一模块。现在新增独立的封面大标题、题目、姓名、学院、专业、导师、学号、日期，以及摘要题目/标签/正文的语义标识。中英文摘要分别映射，保留原有 role/module 接口。
3. **关键词标签和词条混合。** 字体规则现在以 label/value 字符范围分别提取、匹配、写入和回读。中文标签不加粗与英文标签加粗可以同时成立；模板的空词条不会提供虚假的内容字体依据。标签内部混合字体仍保留问题项。
4. **规范作用范围串用。** 现在按显式目标分句，正文、标题、页眉等分别处理，文档段落之间不沿用上段目标。“优秀论文简介”标为独立材料的适用范围问题，未决前不污染主论文规则。编号参考文献示例中的 Georgia 不再借用上一段作用域被识别成执行字体。
5. **字体与粗体概念混淆。** “加黑”解析为 bold，“黑体”解析为字体家族；“不加黑”保留否定。支持小4号/5号等写法。“固定22磅”归入行距，不再误作字号。中文宋体与西文 Times New Roman 是正常的分字体通道设置。
6. **目录缺少真实标题依据。** 原独立生成脚本把章节写成 Normal 段落，插入 TOC 域后 Word 找不到目录项。现在目录算子识别标准/自定义大纲及保守确认的编号标题，为缺失者补充大纲级别，保留字体、样式和编号。显式正文级别不纳入目录。
7. **目录结果验收不足。** 新验收核对范围内标题、目录缓存内容及条目顺序，拒绝空缓存、占位提示、“未找到目录项”等错误。可安全替换完整独立的旧 TOC 域；混有正文/其他独立域、跨段或携带分节符时拒绝自动删除。新增大纲级别以外的非请求修改也会被保护检查拦截。
8. **模板还有行单位段距和异常缩进。** 段前/段后现支持 Word 原生 beforeLines/afterLines，不将半行/一行按假定字号转换成磅。超过可用页宽的首行缩进变为待核实项；空摘要占位段的标题遗留格式不再直接迁移给正文。
9. **段落命中不等于全部属性覆盖。** Profile 计划报告新增 `coverage.target_properties`，列出每个目标实际验收的属性。文档规范要求起草结果必须继续通过项目 plan/apply/verify，inspect 或渲染不能替代格式验收。
