# 通用课程报告模板格式与使用说明

先将 `通用课程报告模板.docx` 另存为自己的报告，再替换方括号中的填写项与写作提示。封面各字段使用原版表格分栏及填写线，填写时在相应单元格内替换文字，不用空格重新排齐标签。

| 区域 | 模板中的设置 |
| --- | --- |
| 页面 | A4，纵向，单栏；上下边距 2.54 cm，左右约 3.17 cm |
| 装订线 | 沿用原版：封面节 0 cm；目录及正文节 1 cm，左侧。左右边距不包含装订线 |
| 页眉及页脚距离 | 页眉约 1.50 cm，页脚约 1.75 cm |
| 学校或单位填写项 | 黑体 22 pt，居中；已去除原校名图 |
| 封面课程及报告类别 | 沿用原版黑体 28 pt，加粗居中；报告题目黑体 16 pt 居中 |
| 封面元数据 | 标签与填写值分栏，个人信息填写值使用宋体三号 16 pt；保留填写线 |
| 一级标题 | 黑体三号 16 pt，加粗居中，段前 24 pt、段后 12 pt，2.4 倍行距；与下段同页、段中不分页 |
| 二级标题 | 黑体四号 14 pt，加粗，沿用原版两端对齐，段前段后 0，约 1.7208 倍行距；与下段同页、段中不分页 |
| 正文 | 中文及西文字体通道均为原版宋体，小四 12 pt，1.5 倍行距，两端对齐，首行缩进 2 字符，段前段后 0 |
| 图示提示及图题 | 五号 10.5 pt，居中；图示提示与下一段同页且提示段内不分页；图题含 SEQ 自动序号 |
| 目录 | TOC 域，显示一、二级标题及实际页码；填充后需更新整个目录 |
| 章节及参考文献序号 | Word 原生自动编号。一级标题形如“第一章”“第二章”，二级标题形如 `1.1`、`2.1`；参考文献形如 `[1]`，参考文献与附录标题不加章号 |
| 页眉及页码 | 页眉为“课程报告”；封面和目录不显示页码，正文从 1 开始 |

模板结构为：封面 → 目录 → 引言 → 任务与要求 → 方案与实施 → 结果与分析 → 总结与体会 → 参考文献 → 附录。没有自动增补摘要、英文摘要或其他原版未要求的模块。

增加正文时，复制已有正文段落并替换文字；新增标题使用已有“标题 1”或“标题 2”样式，并沿用相邻标题的自动编号。不要把已有自动编号再键入一次。一级标题不再强制逐章另起一页，避免简短报告出现多页留白。

插图时，删除“在此插入实际图示”的提示，在该位置插入自己的图片，并填写下方图名。复制图题时保留 SEQ 域，更新后会重新编号。文内交叉引用可使用 Word 的“插入交叉引用”；不要把序号当普通数字反复手改。

文献条目是占位格式，不是真实参考文献。请填入实际引用的来源，删除不需要的条目；附录没有内容时可以整节删除。完成后在 Word/WPS 中更新整个目录，并使用 `Ctrl+A`、`F9` 更新域，再检查分页、图题位置和引用。增加内容后页数自然增长，当前 5 页不构成篇幅要求。

如教师给出了专门的字体、行距或装订要求，以教师要求为准。本模板保留了所选原版的部分非整数行距，没有另行声称这是全国统一格式。
