# 通用课程报告模板来源与改制记录

本模板基于用户选定的上海师范大学天华学院课程考核报告原版改制。改制日期：2026-11-03。本文件是项目内的通用版本，不是学校官方发布的通用模板。

官方来源：https://jwc.sthu.edu.cn/jsbgxz/list.htm ，条目“上海师范大学天华学院课程报告模板”，网页日期 2021-03-02。

模板来源原件及转换副本留作本地溯源资料，不随运行仓库分发。

保留的版式依据：原版两节的 A4 纸张、页边距、装订线、页眉页脚距离、单栏与文档网格；封面元数据分栏表格与填写线；宋体小四正文、1.5 倍行距、首行缩进 2 字符、段前段后 0；黑体三级字号的一级标题、四号的二级标题及原有 TOC 目录样式。样式、主题和字体表经 XML 规范化比较与原版一致；不把 XML 序列化差异描述为逐字节一致。

按“改成通用模板”的要求做了以下改制：

- 校名及页眉标识改为通用填写项或“课程报告”；移除课程专用评分表。
- 学院、班级、姓名、学号、教师、日期和课程题目替换为占位内容；补齐学号填写值的字号，使其与其他个人信息值一致。
- 数字图像处理专业叙述改为通用写作提示，保留五章顺序和原有二级层级。参考文献只保留书籍与网页的占位格式，附录保留填写提示。
- 删除原图像、公式对象、示例书目、批注和颜色提示；包内不再保留原校名图、示例图片或嵌入对象。
- 手打章节号、参考文献序号改为 Word 原生编号，图题使用 SEQ 域；目录已在 WPS 中刷新。按用户后续要求，一级标题使用“第一章、第二章……”自动编号，二级标题保留 `1.1`、`2.1` 等形式。
- 取消示例用的逐章强制分页，清理多余空段；保留封面、目录与正文的边界，正文从 1 开始显示页码。

当前模板共 5 页：封面、目录、3 页正文及附属内容。5 页是占位稿的当前长度，不是填写时的篇幅限制。已核对目录页码、自动编号、段落设置并逐页查看渲染页。

模板已完成格式、编号及逐页视觉核对，验收材料保留于本地。模板成品由项目格式引擎输出，未将起草脚本直接保存的草稿当作成品。
