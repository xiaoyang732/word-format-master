# 课程考核报告模板格式核对说明

以下是对学校原件经 WPS 转换后的 DOCX 副本所作的实际回读记录，不是另行设计的排版规则。单位换算存在少量四舍五入差异，原件优先。

| 区域 | 已有设置 | 依据 |
| --- | --- | --- |
| 纸张 | A4，纵向 | 两节页面参数 |
| 页边距 | 上、下 2.54 cm；左、右约 3.17 cm | 两节页面参数 |
| 页眉、页脚距离 | 页眉约 1.50 cm，页脚约 1.75 cm | 两节页面参数 |
| 封面 | 校名图、评分表、课程名称、题目、信息填写线及日期分别布局；元数据标签与填写值分栏 | 原件封面，不把全部内容设为同一种居中段落 |
| 正文示例 | 宋体小四 12 pt，1.5 倍行距，两端对齐，首行缩进 2 字符，段前段后 0 | “数字图像信息具有直观…”段落；西文字体通道也为宋体，不能擅称全篇 Times New Roman |
| 一级标题示例 | 黑体三号 16 pt，加粗，居中，段前 24 pt、段后 12 pt，2.4 倍行距；与下段同页、段中不分页、段前分页 | “1引言”段落；其他标题的个别属性存在差异 |
| 二级标题示例 | 黑体四号 14 pt，加粗，两端对齐；段前段后 0，约 1.7208 倍行距，与下段同页、段中不分页 | “2.1课程设计题目”段落；不强行简化为统一的 1.5 倍 |
| 图题示例 | 中文宋体、西文 Times New Roman，五号 10.5 pt，居中，1.5 倍行距，段前段后 0 | “图3.1 中值滤波原理图”段落 |
| 目录 | 使用 TOC 域及目录样式；可刷新实际页码 | 目录页与字段 XML |
| 正文页码 | 正文从 1 开始；封面与目录无可见页码 | 渲染页 1—13 |

原件中的粉红色、紫色等底纹属于原有提示，并未清除。原文件的目录页、主要章节、参考文献和附录采用分页安排；个别章节末尾留白较多，部分结果分图跨页。副本共 13 页，页数包含原示例内容，并不规定今后报告必须写成 13 页。

章节名、图题和参考文献中存在手工数字，不能把原版外观等同于已配置完整的动态编号。后续使用项目生成报告时，应在新稿中建立原生章节编号、SEQ 图题和 REF 引用，并重新刷新目录、检查图片与题注的分页。原版参考文献和图像仅用于展示版式，未进行文献事实核验，不应直接当成新报告的研究证据。
