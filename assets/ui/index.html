    论文题目1

    城市绿色基础设施对夏季热暴露的缓解效应

    张明　李然

    城市环境与空间分析实验室

    摘要：本研究融合遥感、街区传感器与地表覆盖数据，评估不同尺度绿色基础设施对高温暴露的影响。

    关键词：绿色基础设施；热暴露；空间分析

    1 研究背景

    快速城市化改变了地表能量平衡。连续观测显示，树冠覆盖与遮阴连通性能够降低午后行人层热暴露。

    1.1 数据与方法

    研究在典型居住区布设微气候节点，并以同一时间窗的卫星地表温度校正传感器观测。

    1.1.1 指标构建

    模型纳入树冠率、天空可视因子与不透水面比例，采用分层交叉验证比较预测误差。

    1. 街区尺度环境特征
    2. 逐小时热暴露指标
    3. 空间缓冲区设置
    4. 稳健性检验方案
    5. 结果复核记录

    HI = 0.62T + 0.38RH

    在不同缓冲半径与缺失值处理方案下，主要效应方向保持一致。
